# 人机双写

> 细微调整随手就改，复杂改写交给 AI。

人机双写是右侧边栏文件预览区中的 AI 协作编辑能力。在 WorkBuddy 内，用户既可以像平时一样手动输入和编辑文档，也可以随时发出指令，让 WorkBuddy 根据要求直接在当前文档中进行增删、改写或排版。该功能由腾讯文档提供底层技术支持。

## 核心亮点

* **内置编辑，无需跳转外部工具**：在 WorkBuddy 内直接编辑 Word / Excel / PPT / Markdown 及腾讯文档，阅读、手动修改与 AI 辅助在同一界面完成，避免在本地 Office 软件之间来回切换。
* **人机同区，修改实时同步**：人与 AI 在同一编辑区协作，手动修改的内容 WorkBuddy 实时感知，后续 WorkBuddy 改写始终基于最新版本进行，避免内容覆盖。
* **选区精调，精准定位修改范围**：选中具体的文字或区域后下达指令，WorkBuddy 仅针对选区内容进行调整，无需通过截图或复制长文描述目标，减少 Token 消耗。

## 两种编辑方式

人机双写由两种编辑方式组成，作用于同一份文件，彼此感知：

* **AI 编辑**：选中具体的文字或区域，下达指令让 AI 针对性地进行调整。适用于整段润色、排版重构、内容生成、公式批量处理等复杂操作。
* **手动编辑**：错别字、字号等简单操作人工直接改，不消耗 Token；改完的内容 WorkBuddy 也能感知。

两种方式按修改粒度互补使用：细节微调手动改最快，大块重构交给 AI。

## 快速开始

以 Word / Markdown 为例，一次典型的人机双写流程：

1. **打开文件** 在任务流中点击文件，右侧边栏展开文件预览，可直接手动编辑文件内容。
2. **选中内容** 选中某段文字或元素，划词后出现工具栏，工具栏上有「AI 编辑」按钮。

   ![选区并出现工具栏](/docs/static/right-sidebar-3.Bp5JK2jF.png)
3. **下达指令** 点击「AI 编辑」展开评论框，输入修改要求并发送。支持批量添加需要修改的内容，最后一次性点击「发送」。

   ![输入编辑指令](/docs/static/right-sidebar-4.SDp2TS4K.png)
4. **AI 改写** 将引用内容和评论发送给 WorkBuddy ，让他针对被引用的元素精准调整，并告知用户改了哪里。

   ![发送到AI输入框](/docs/static/right-sidebar-5.BDC5FEq9.png)

## 场景应用

### 文档（Doc）

框选内容自动进入对话上下文，让 WorkBuddy 在指定位置补内容。

* **排版美化与总结**：针对性排版并生成全文总结
* **润色与改写**：按指令对多段文本润色，强化重点

![案例-表格](/docs/static/right-sidebar-6.p4yT4_lv.png)

### 表格（Excel）

支持单元格 / 行列 / 整表等多种选区形式，复杂数据处理与可视化也能覆盖。

* **数据透视分析**：框选数据区域，多维透视一次到位
* **数据分析报告**：WorkBuddy 出分析 + 图表 + 结论

![案例-表格](/docs/static/right-sidebar-7.BmD8908e.png)

### PPT

支持点选或框选 PPT 元素，具备以下独有能力：

* **选页做 AI 编辑**：选中整页下达指令，不必逐个元素操作
* **自由框选模式**：画布上框选区域，生成结果精准落在指定位置
* **风格统一**：选中基准页面，刷新整份 PPT 视觉风格

![案例-Markdown](/docs/static/right-sidebar-8.Z8Xr9W_z.png)

### Markdown

点选或框选文字、标题、列表或代码块进入对话上下文，WorkBuddy 按指令改写或重排。

* **结构重排**：选中段落重新组织标题层级
* **内容续写**：光标停在标题下，就地续写

![案例-Markdown](/docs/static/right-sidebar-9.DLxQkT91.png)

## 注意事项与重点提示

### 信息收集与使用

| 收集项 | 类型 | 用途 |
| --- | --- | --- |
| 文档内容 | 必要 | WorkBuddy 根据文档现有内容进行理解、改写和排版 |
| 选区内容 | 非必要 | 用户选中特定文字或区域后，WorkBuddy 针对选区进行精准修改 |
| 编辑指令 | 非必要 | 用户输入的修改要求，作为 WorkBuddy 改写的依据 |
| 手动编辑记录 | 非必要 | 记录用户手动修改的内容，确保 WorkBuddy 在最新版本基础上进行后续操作 |

### 权限边界

* 人机双写仅对用户主动打开的文档进行操作，不主动扫描或读取其他文件
* WorkBuddy 修改范围限于用户选区或明确指令指向的内容，不超出用户指定范围
* 所有 WorkBuddy 改写均可核对和撤销

### 安全提示

* 文档编辑在 WorkBuddy 内完成，无需跳转外部软件，减少文件泄露风险
* WorkBuddy 改写前会展示指令内容，用户确认后执行，避免误操作
* 建议定期通过「变更」面板检查 WorkBuddy 修改记录，确保内容符合预期

### 积分消耗提醒

手动编辑不消耗积分；AI 编辑（包括改写、润色、排版、生成内容等）会消耗积分。选区精调相比全文描述可节省 Token 消耗。

### 技术支持

人机双写功能由腾讯文档提供底层技术支持；文档内容由 WorkBuddy 维护以供编辑和处理。

### 免责声明

WorkBuddy 改写内容的准确性和适用性由用户自行判断，WorkBuddy 不对生成内容的具体效果做保证，请审慎核对后再使用。

### 使用建议

* 复杂改写建议分步进行：先让 WorkBuddy 生成初稿，再通过选区精调逐步优化，避免一次性大改导致内容偏离预期。
* PPT 场景下善用「自由框选模式」和「选页编辑」，可大幅提升多元素文档的编辑效率。
* 涉及重要文档时，建议先「另存为新文件」再进行 AI 改写，保留原始版本以便回溯。
